# Aplikasi Peminjaman Buku

Aplikasi web untuk mengelola peminjaman dan pengembalian buku perpustakaan sekolah. Dibuat untuk Uji Kompetensi Keahlian (UKK) 2026.

## Fitur Utama

**Admin**

- Kelola data buku (CRUD)
- Kelola transaksi peminjaman (CRUD)
- Kelola data anggota (CRUD)

**Siswa**

- Login dan melihat dashboard siswa
- Melakukan peminjaman buku
- Melakukan pengembalian buku

## Teknologi

- PHP (Laravel) dan Filament (panel admin)
- MySQL
- Composer

> Isi versi Laravel, Filament, dan PHP di sini (lihat `src/composer.json`).

## Struktur Repo

